# Go2 关键帧轨迹记录与回放系统

## 项目概述

本项目是一个专为 Go2 四足机器人设计的关键帧轨迹记录与回放系统。该系统允许用户记录机器人的关键姿态和动作序列，并能够精确地重现这些轨迹，实现复杂动作的编程与执行。系统基于 MuJoCo 仿真环境开发，支持仿真测试和实机部署。

## 功能特点

- **关键帧记录**：捕获机器人在特定时刻的完整姿态信息
- **轨迹回放**：精确重现预先记录的动作序列
- **插值平滑**：在关键帧之间进行平滑插值，实现流畅的动作过渡
- **阻尼控制**：通过调整关节阻尼，实现更自然的拖拽和姿态调整
- **球体拖拽控制**：通过可视化控制球体直观地拖拽和调整机器人姿态
- **仿真与实机兼容**：支持在仿真环境和实体机器人上测试
- **模块化设计**：代码结构清晰，便于维护和扩展

## 使用方法

### 关键帧记录

使用 `recorder_damping.py` 记录机器人姿态：

```bash
python recorder_damping.py
```

#### MuJoCo窗口操作说明：
- 按住Ctrl并用鼠标拖动机器人的各个部位调整姿势
- 拖拽时，相关关节的阻尼会自动设为0，松开后恢复
- 使用可视化控制球体（彩色球体）直接拖拽调整机器人姿态
- 按S键保存当前姿势作为关键帧
- 按[键减少阻尼，按]键增加阻尼
- 按ESC键退出程序

#### UI界面操作说明：
- **滑动条控制**：每个关节都有对应的滑动条，可以精确调整关节角度
  - 鼠标拖动滑动条改变关节角度
  - 鼠标悬停在滑动条上，使用滚轮微调角度（向上增加，向下减少）
  - 滑动条右侧显示当前角度值和关节限位范围
- **按钮功能**：
  - "重置所有关节"：将所有关节恢复到初始位置
  - "保存关键帧"：保存当前姿势作为关键帧
  - "保存所有关键帧"：将所有已记录的关键帧保存到文件
- **关键帧计数**：界面顶部显示当前已记录的关键帧数量
- **关节分组**：关节按照功能和位置分组显示，便于操作

关键帧会自动保存到keyframes目录，文件名包含时间戳，格式为npz。

### 轨迹直接回放

使用 `keyframe_direct_player.py` 直接回放已记录的轨迹：

```bash
python keyframe_direct_player.py
```

操作说明：
- 程序启动后，选择要回放的关键帧文件
- 设置每个关键帧的停留时间
- 选择是否显示详细信息和启用调试模式
- 设置初始等待时间，让机器人到达初始位置
- 调整关节阻尼值以匹配录制环境
- 按Enter键显示下一个关键帧
- 按ESC键退出程序

### 轨迹插值回放

使用 `keyframe_interpolation_player.py` 进行平滑插值回放：

```bash
python keyframe_interpolation_player.py [--fps 30] [--duration 2.0] [--loop] [--speed 1.0] [--initial-wait 3.0] [--damping 10.0]
```

参数说明：
- `--fps`：播放帧率，默认30fps
- `--duration`：每对关键帧之间的过渡时间(秒)，默认2.0秒
- `--loop`：是否循环播放
- `--speed`：回放速度倍率，大于1加速，小于1减速
- `--initial-wait`：初始等待时间(秒)，默认3.0秒
- `--damping`：关节阻尼值，默认10.0

操作说明：
- 程序启动后，选择要回放的关键帧文件
- 设置是否显示详细信息
- 调整初始等待时间和关节阻尼值
- 系统会自动在关键帧之间进行平滑插值
- 按ESC键退出程序

## 开发说明

- **关键帧数据格式**：关键帧数据以NumPy的npz格式保存，包含时间戳和所有关节的角度信息
- **阻尼控制机制**：系统通过动态调整关节阻尼，实现拖拽时的灵活性和静止时的稳定性
- **球体拖拽控制**：通过在模型中添加可视化控制球体，实现更直观的姿态调整
  - 不同颜色的球体对应不同的控制点
  - 拖拽球体可以直接控制机器人相应部位的位置和姿态
  - 提供更直观的交互体验，减少对关节角度的直接操作
- **插值算法**：轨迹回放使用线性插值和球面线性插值(SLERP)，确保动作平滑自然
- **UI界面**：提供直观的滑动条控制界面，方便精确调整关节角度
  - 滑动条根据关节限位范围自动设置
  - 实时显示当前角度值和限位范围
  - 支持鼠标滚轮微调，步长为限位范围的0.5%
  - 跨平台支持（Windows、Linux、macOS）
- **多线程设计**：使用线程安全的方式处理UI更新和物理模拟，确保系统稳定运行

## 注意事项

- 确保MuJoCo环境正确安装并能够加载模型
- 录制和回放时使用相同的模型文件和阻尼设置，以确保动作一致性
- 初始等待时间对于确保机器人到达正确的初始位置非常重要
- 对于复杂动作，建议使用插值回放以获得更流畅的效果
- 在拖拽调整姿势时，建议先降低阻尼值，完成后再增加阻尼以保持稳定
- 使用控制球体拖拽时，系统会自动处理相关关节的阻尼调整
- UI界面和物理模拟运行在不同线程，确保系统响应性和稳定性

## 扩展与定制

- 可以通过修改 `joint_descriptions` 字典来自定义关节描述
- 可以调整 `utils/ui_controller.py` 中的UI布局和样式
- 可以在 `utils/keyframe_manager.py` 中扩展关键帧数据格式和处理方法
- 可以通过修改 `utils/joint_utils.py` 中的函数来调整关节控制行为
- 可以在 `go2/scene_zero_gravity_free_draggable.xml` 中调整控制球体的位置和大小
